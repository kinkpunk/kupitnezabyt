# Дизайн-система kupitnezabyt

Источник: дизайн-ревью экрана «Категории» (август 2026). Документ фиксирует правила и токены, на которые ссылается план редизайна. Токены из раздела 2 — единственный источник значений цвета в коде; хардкод hex вне файла токенов запрещён.

---

## 1. Правила

### 1.1. Акцент — не семантика

Розовый `#F19FA7` используется только для бренда и главного действия на экране (primary-кнопка, активный таб, FAB, прогресс). Статусы, архив, уведомления имеют собственные роли и не окрашиваются в брендовый цвет. На экране — не более одной primary-кнопки.

### 1.2. Статусы — семантические цвета

Три статуса товара — три устойчивых цвета с точкой-индикатором:

- **Есть** — зелёный;
- **Мало** — янтарный;
- **Нет** — красный.

Статусные цвета не совпадают с брендовым и читаются на тёмном и светлом фоне. Подложка статуса — тот же цвет с альфой 12–15%.

### 1.3. Контраст и группировка

- Контраст текста к фону — не ниже **4.5:1**.
- Группировка элементов — отступами и поверхностями. Обводки — только hairline (`line`, 1px). Карточки с рамками в списках не используются.

### 1.4. Типографика

Три уровня, новые размеры вне шкалы — только через ревью:

| Уровень | Размер | Назначение |
|---|---|---|
| Заголовок | 19 | заголовки экранов и секций |
| Название | 15 | названия товаров, заголовки карточек |
| Вторичное | 12–13 | подписи, метаданные, чипы |

### 1.5. Сетка и форма

- Шаг сетки: **4 px**; базовые отступы: **16 / 20**.
- Радиусы: **12 / 16 / full**.
- Строка списка: высота 72, разделитель hairline.
- Tap-target: не меньше 44 px.

### 1.6. Статусы товара и доменная модель

В дизайн-системе три видимых статуса. В доменной модели (`ItemStatus`) четыре значения; три видимых статуса маппятся на них следующим образом:

| Видимый статус | Доменный статус | Цвет |
|---|---|---|
| **Есть** | `IN_STOCK` | `status/ok` |
| **Мало** | `LOW` | `status/warn` |
| **Нет** | `NEED_BUY` | `status/bad` |

`PAUSED` — отдельное состояние товара, не участвует в цикле быстрого статуса и отображается в интерфейсе как «Пауза»/«Не отслеживается» без цветового акцента статуса.

## 3. Компонентные правила

- **StatusChip** — статус товара: точка 8px + подпись, подложка статуса, высота 32, горизонтальный отступ 12px, радиус 9px (как у компактной кнопки). Фиксированная минимальная ширина 78px под самую длинную подпись («Пауза»), контент центрируется — чипы всех статусов («Есть/Мало/Нет/Пауза») одинаковой ширины и не «скачут» при смене статуса. Используется `min-width`, а не `width`: при подстановке системного шрифта шире ожидаемого чип вырастет, а не обрежет текст. Тап циклирует «Есть → Мало → Нет». Выпадающие списки статуса не используются.
- **Button**: `primary` (заливка `brand`, текст `on-brand`), `ghost` (обводка `line`, текст `text/2`), `icon` (34×34 / 40×40, прозрачный фон). Компактная кнопка — 32px высота, отступы 0 12px, радиус 9px. Все компактные контролы (чипы, табы) повторяют её форму.
- **CategoryTabs** (стиль «линия», по образцу Ant Design basic): подложек нет, фон прозрачный; активный таб — текст `brand` + полоса `brand` на всю ширину таба (3px, радиус full) под текстом; предупреждение — точка `status/warn`, а не иконка ⚠. Неактивный — текст `text/2`. Таб: min-height 32px, отступы 0 12px; размер шрифта — `md`. В конце строки табов — иконная кнопка «Новая категория» (`icon`, прозрачный фон, иконка `plus`), открывающая bottom-sheet создания; в шапке экрана её нет. Когда не все табы помещаются, по краям ряда показываются динамические градиент-фейды к `bg/base` (28px, `pointer-events: none`): правый — пока есть скрытые табы справа, левый — при прокрутке вправо; на концах списка фейды гаснут.
- **ProductRow**: название + подпись «Обновлено … · Категория» + `StatusChip` + кнопка «ещё» (`ellipsis-vertical`), которая открывает bottom-sheet с действиями. Стрелки сортировки в обычном режиме не показываются.
- **PanelHeader** — сводка и фильтр категории в виде раскрывающейся панели (инлайн-аккордеон). Свёрнутое состояние — одна иконная кнопка «Фильтры и действия» (`icon`, прозрачный фон, иконка `sliders-horizontal`) в правом крае строки; при активном фильтре (не «Все») на кнопке — точка-индикатор `brand` с обводкой `bg/base`. По нажатию панель разворачивается на месте (появление 160ms), список ниже сдвигается. В развёрнутой панели две строки, выровненные по правому краю: сверху чипы-фильтры по статусу («Все», «Есть», «Мало», «Нет») со счётчиками (при нехватке ширины переносятся на следующую строку, скролла нет), снизу — действия: текстовая кнопка «В архив» с иконкой `archive` (как в bottom-sheet товара) и primary «Проверить». Панель сворачивается при нажатии «Проверить»/«Архив» и при смене категории (состояние сбрасывается remount через `key`); при смене фильтра остаётся открытой. Чип фильтра: высота 32px, отступы 0 12px, радиус 9px; неактивный — прозрачный фон, обводка `line`, текст `text/2`, точка статуса 8px; активный — подложка `surface/2`, текст `text/1` (для статусных чипов — soft-подложка и текст соответствующего статуса), обводки нет. Текстовая кнопка «В архив» — min-height 32px, отступы 0 12px, иконка 18px слева с отступом 12px, прозрачный фон, цвет `text/3`; при наведении фон `surface/2`. Прогресс-бара в шапке категории нет — его роль выполняют счётчики чипов (компонент остаётся на экране проверки).
- **BottomNav**: фон `nav/bg`, активный пункт — цвет `brand` + точка-индикатор 5px, без плашки на весь слот. Слот: min-height 48px, горизонтальный отступ 8px.
- **FAB** — добавление товара: круг 52px, `brand`, иконка `plus`.
- **NotificationBadge** — метка в списке уведомлений: высота 24px, отступы 0 8px, радиус 9px (тот же радиус, что у компактных контролов); фон `surface/2`, текст `text/3`, срочный вариант — подложка и текст `status/bad`.
