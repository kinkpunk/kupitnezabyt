# Дизайн-система kupitnezabyt

Источник: дизайн-ревью экрана «Категории» (август 2026). Документ фиксирует правила и токены, на которые ссылается план редизайна. Токены из раздела 2 — единственный источник значений цвета в коде; хардкод hex вне файла токенов запрещён.

---

## 1. Правила

### 1.1. Акцент — не семантика

Розовый `#F19FA7` используется только для бренда и главного действия на экране (primary-кнопка, активный таб, FAB, прогресс). Статусы, архив, уведомления имеют собственные роли и не окрашиваются в брендовый цвет. На экране — не более одной primary-кнопки.

### 1.2. Статусы — семантические цвета

Три статуса товара — три устойчивых цвета с точкой-индикатором:

- **Есть** — зелёный;
- **Мало** — янтарный;
- **Нет** — красный.

Статусные цвета не совпадают с брендовым и читаются на тёмном и светлом фоне. Подложка статуса — тот же цвет с альфой 12–15%.

### 1.3. Контраст и группировка

- Контраст текста к фону — не ниже **4.5:1**.
- Группировка элементов — отступами и поверхностями. Обводки — только hairline (`line`, 1px). Карточки с рамками в списках не используются.

### 1.4. Типографика

Три уровня, новые размеры вне шкалы — только через ревью:

| Уровень | Размер | Назначение |
|---|---|---|
| Заголовок | 19 | заголовки экранов и секций |
| Название | 15 | названия товаров, заголовки карточек |
| Вторичное | 12–13 | подписи, метаданные, чипы |

### 1.5. Сетка и форма

- Шаг сетки: **4 px**; базовые отступы: **16 / 20**.
- Радиусы: **12 / 16 / full**.
- Строка списка: высота 72, разделитель hairline.
- Tap-target: не меньше 44 px.

### 1.6. Статусы товара и доменная модель

В дизайн-системе три видимых статуса. В доменной модели (`ItemStatus`) пять значений; три видимых статуса маппятся на них следующим образом:

| Видимый статус | Доменный статус | Цвет |
|---|---|---|
| **Есть** | `IN_STOCK` | `status/ok` |
| **Мало** | `LOW` | `status/warn` |
| **Нет** | `NEED_BUY`, `URGENT` | `status/bad` |

`PAUSED` — отдельное состояние товара, не участвует в цикле быстрого статуса и отображается в интерфейсе как «Пауза»/«Не отслеживается» без цветового акцента статуса.

`URGENT` сохраняет свой приоритет в списке покупок и агрегированном статусе категории, но в UI товара отображается тем же красным цветом, что и `NEED_BUY`.

## 3. Компонентные правила

- **StatusChip** — статус товара: точка 8px + подпись, подложка статуса, радиус full, высота 30. Тап циклирует «Есть → Мало → Нет». Выпадающие списки статуса не используются.
- **Button**: `primary` (заливка `brand`, текст `on-brand`), `ghost` (обводка `line`, текст `text/2`), `icon` (34×34 / 40×40, фон `surface/1`).
- **CategoryTabs**: активный — заливка `brand`, текст `on-brand`; предупреждение — точка `status/warn`, а не иконка ⚠. Неактивный — `surface/2`, текст `text/2`.
- **ProductRow**: название + подпись «Обновлено … · Категория» + `StatusChip` + кнопка «ещё» (`ellipsis-vertical`), которая открывает bottom-sheet с действиями. Стрелки сортировки в обычном режиме не показываются.
- **BottomNav**: фон `nav/bg`, активный пункт — цвет `brand` + точка-индикатор 5px, без плашки на весь слот.
- **FAB** — добавление товара: круг 52px, `brand`, иконка `plus`.
